PureComponent​

React는 VDOM으로 해당 Component나 상위 Component의 state가 변경되었을 때만 DOM 요소를 업데이트 해준다.

하지만 PureComponent를 사용하는 이유를 찾아보면 또 state가 변경될 때 마다 모든 Component가 re-render 된다고 한다.😵
